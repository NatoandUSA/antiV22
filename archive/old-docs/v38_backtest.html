The three problems the data exposes

1 · MATH-02 rewards missing data, and rewards the wrong thing. The formula adds +10 × (1 − sellers/listings), so fewer sellers → higher competition-health. Its stated goal is “favor multi-seller hobbyist niches over single-seller monopolies” — the formula does the opposite. Worse, 778 of 1,123 rows have seller_count = 0 and collect the maximum +10 simply because the field is empty. Mean competition-health rises +8.2 pts across the whole corpus — indiscriminate, not selective.
2 · MATH-01 argues against a formula you no longer run. The spec says it fixes the “linear clamp min(100, cr·2000).” Your current code was already fixed (V33) to a smooth piecewise curve. The proposed logistic (k=100, midpoint 2.5%) is actually steeper at the median — more sensitive to a 1% wobble near 2.5%, not less — and it never returns 0 (a 0% converter still scores ~7.6). It lifts Market by +3.2 pts on average, again only upward.
3 · Neither change adds a single conservative signal. Across 1,123 keywords, 0 verdicts became more cautious. A tuning change that only ever raises scores isn’t re-balancing the ranking — it’s loosening it. That’s the opposite of what the 90-day freeze was protecting.

If you still want to improve these two components, the safe order is:
  1. Fix seller-count coverage first. With 69% of rows at 0, any seller-based term is noise until the data is real. This is a data problem, not a formula problem.
  2. If a seller term is added: gate it on seller_count > 0, invert it to penalize concentration (match the stated intent), and make it zero-mean (a bonus and a penalty) so it discriminates instead of inflating everyone.
  3. MATH-01 is low priority. The current curve is already smooth. If you adopt a logistic, fit k and the midpoint against keywords with known outcomes — don’t guess — and re-center it so 0% conversion scores 0.
  4. Keep it behind the freeze until backtested against real sell-through, not just re-scored on the same inputs. This test shows the direction (up, for everyone); it can’t tell you the new scores are more correct.
